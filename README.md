# Vivance Art

Site statique de [Vivance Art](https://www.vivanceart.com), galerie d'art contemporain latino-américain à Paris.

Pages : accueil, artistes (une page par artiste), œuvres (une page par œuvre, achat via la boutique en ligne), expositions, encadrement, à propos, contact, mentions légales.
Contenu dans `data/site.json`, pages générées par `python3 gen.py`.
